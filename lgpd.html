Privacidade e Segurança

Política de Privacidade e LGPD

Esta política apresenta, de forma clara e objetiva, como o sistema acadêmico Raízes do Nordeste trata as informações dos usuários durante o uso das funcionalidades de cadastro, pedidos, carrinho e programa de fidelidade.

1. Objetivo

A presente Política de Privacidade tem como objetivo informar ao usuário quais dados podem ser solicitados durante a utilização do sistema Raízes do Nordeste, bem como explicar as finalidades de uso dessas informações dentro do projeto.

Este sistema foi desenvolvido para fins acadêmicos, como parte de um projeto front-end, e não possui finalidade comercial. Ainda assim, a interface busca simular boas práticas de transparência, consentimento e proteção de dados conforme os princípios da Lei Geral de Proteção de Dados Pessoais (LGPD - Lei nº 13.709/2018).

2. Dados coletados no sistema

Durante o uso da aplicação, alguns dados podem ser informados pelo usuário para permitir a simulação das funcionalidades principais. Entre eles, destacam-se:

  • Nome completo, utilizado para identificação do usuário no sistema;
  • E-mail, utilizado para cadastro e login;
  • Senha, utilizada apenas para simular o processo de autenticação;
  • Região selecionada, utilizada para exibir o cardápio correspondente;
  • Itens adicionados ao carrinho;
  • Histórico de pedidos realizados;
  • Pontos acumulados no programa de fidelidade.

3. Finalidade do uso dos dados

Os dados informados são utilizados exclusivamente para viabilizar a experiência simulada do usuário dentro da aplicação. As principais finalidades são:

  • Permitir o cadastro e login do usuário;
  • Liberar funcionalidades restritas, como carrinho, pedidos, perfil e fidelidade;
  • Exibir produtos conforme a região escolhida;
  • Registrar pedidos simulados;
  • Calcular e apresentar pontos de fidelidade;
  • Melhorar a clareza do fluxo de navegação e da experiência do usuário.

4. Armazenamento das informações

Por se tratar de uma aplicação front-end sem backend real, os dados são armazenados localmente no navegador do usuário por meio do recurso localStorage. Isso permite simular a persistência de informações, como login, carrinho, pedidos e pontos de fidelidade.

O sistema não envia dados para servidores externos, bancos de dados reais ou serviços de terceiros. Ao limpar os dados do navegador, as informações armazenadas localmente podem ser removidas.

5. Pagamento externo simulado

O sistema não realiza pagamentos reais. A etapa de pagamento é representada apenas como uma simulação de integração externa, com o objetivo de demonstrar o fluxo esperado em um sistema de pedidos.

Após a finalização do pedido, a aplicação simula a confirmação do pagamento e registra o pedido com status inicial de preparo. Nenhum dado bancário, cartão de crédito, chave PIX ou informação financeira real é coletado pelo sistema.

6. Compartilhamento de dados

Como o projeto é acadêmico e utiliza apenas armazenamento local, não há compartilhamento de dados com empresas, fornecedores, parceiros comerciais ou sistemas externos reais.

A integração com pagamento externo, quando mencionada no sistema, possui caráter exclusivamente demonstrativo e não realiza comunicação com plataformas de pagamento.

7. Consentimento do usuário

No momento do cadastro, o usuário deve aceitar o termo de consentimento relacionado ao uso de seus dados para cadastro, pedidos e participação no programa de fidelidade. Esse consentimento é uma forma de tornar explícita a finalidade do tratamento das informações dentro do sistema.

Também é exibido um aviso de privacidade na interface, reforçando a transparência no uso dos dados.

8. Direitos do titular dos dados

Conforme os princípios da LGPD, o usuário tem direito à informação clara sobre o uso de seus dados, bem como à possibilidade de solicitar acesso, correção ou exclusão das informações. Neste projeto, como os dados ficam armazenados localmente no navegador, o próprio usuário pode removê-los limpando os dados do site no navegador ou utilizando os fluxos simulados da aplicação.

9. Segurança e limitações do projeto

Embora o sistema simule práticas relacionadas à privacidade, ele não deve ser utilizado como aplicação real de produção. Em um ambiente profissional, seria necessário implementar backend seguro, banco de dados, criptografia de senhas, autenticação robusta, controle de acesso e integração segura com serviços externos.

A senha informada no cadastro é utilizada apenas para fins de simulação acadêmica. Em sistemas reais, senhas nunca devem ser armazenadas em texto puro, devendo ser protegidas por técnicas adequadas, como hash criptográfico.

10. Considerações finais

Esta Política de Privacidade reforça o compromisso do projeto Raízes do Nordeste com a clareza, a transparência e a responsabilidade no uso de dados pessoais, mesmo em um ambiente acadêmico e simulado.

O objetivo principal é demonstrar que a experiência do usuário, a proteção de dados e a conformidade com a LGPD devem ser consideradas desde as etapas iniciais de planejamento e desenvolvimento de uma interface.
