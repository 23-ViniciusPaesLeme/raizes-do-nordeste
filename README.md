# 🌵 Raízes do Nordeste

Sistema web de pedidos online inspirado na culinária nordestina, desenvolvido como projeto acadêmico para a disciplina de Desenvolvimento Front-End.

O sistema simula uma plataforma de delivery com foco em experiência do usuário, regras de negócio e integração de funcionalidades modernas, como fidelização, promoções e pagamento externo.

# 🧩 Funcionalidades

## 👤 Autenticação
- Cadastro de usuário com validação
- Login com persistência de sessão utilizando LocalStorage
- Controle de acesso para funcionalidades protegidas

---

## 🏪 Seleção de Unidade

O sistema trabalha com unidades físicas da rede, permitindo que cada localidade possua um cardápio personalizado.

Exemplos de unidades:
- Recife – PE
- São Paulo – SP
- Goiânia – GO
- Curitiba – PR

Cada unidade possui produtos específicos disponíveis para venda.

---

## 🍽️ Cardápio Inteligente
- Seleção de unidade
- Busca por nome e descrição
- Filtro por categorias:
  - pratos
  - bebidas
  - sobremesas
  - lanches
- Produtos sazonais exibidos apenas em períodos específicos
- Cardápio personalizado por unidade

---

## 🛒 Carrinho de Compras
- Adição e remoção de itens
- Cálculo automático de subtotal e total
- Persistência de dados no navegador
- Integração com sistema promocional

---

## 💳 Pagamento Externo (Simulado)
- Integração simulada com sistema de pagamento externo
- Feedback visual de processamento e aprovação
- Registro de pedidos após confirmação do pagamento

---

## 🎯 Sistema de Promoções
- Aplicação automática de campanhas promocionais
- Regras de desconto baseadas em condições de compra
- Promoções aplicadas dinamicamente ao carrinho

### Exemplo de campanha:
- Pedido acima de R$ 60,00
- Inclusão de prato típico nordestino
- Desconto automático no valor final

---

## ⭐ Programa de Fidelidade
- Acúmulo de pontos baseado no valor dos pedidos
- Sistema de resgate de recompensas
- Controle de recompensas já utilizadas
- Barra visual de progresso

---

## 📦 Gestão de Pedidos
- Histórico de pedidos realizados
- Acompanhamento de status:
  - recebido
  - em preparo
  - pronto
- Exibição de itens, valores e promoções aplicadas

---

## 🔒 LGPD
- Aceite de termos de privacidade
- Controle de consentimento do usuário
- Armazenamento local da autorização

---

# 🧠 Regras de Negócio Implementadas

# 🎓 Considerações Acadêmicas

Este projeto foi desenvolvido com o objetivo de simular um sistema real de pedidos online, aplicando conceitos fundamentais de desenvolvimento front-end, como:

- experiência do usuário (UX)
- regras de negócio
- integração entre módulos
- organização e estruturação de código
- responsividade
- persistência de dados no navegador

O uso do framework **Bootstrap** foi adotado para garantir responsividade e padronização visual, atendendo aos requisitos técnicos da atividade proposta.
